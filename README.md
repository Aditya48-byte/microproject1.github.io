# Microproject 1 – Express.js Application

A small Express.js web application created for COMP2140.  
The project includes a multi-page interface, a JSON API, and a modern login/sign-in user interface.

## 🔹 What This Project Includes
- Express.js server with organized routes  
- Static frontend (HTML, CSS, JS)  
- Login and Sign-In pages with clean professional design  
- Background image authentication screens  
- Navigation bar with dropdown login menu  
- JSON data served from the backend  
- Fetch API using async/await to display data as cards
